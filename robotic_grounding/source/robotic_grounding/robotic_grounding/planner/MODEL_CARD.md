# Model Overview

## Description:
The v2d MotionBricks Planner is a whole-body motion generation model that produces full-body humanoid (Unitree G1) reference trajectories from end-effector and root targets. Given desired left/right wrist (end-effector) position and orientation trajectories together with a root pose trajectory, the model autoregressively generates a physically-plausible whole-body motion — root translation plus a 29-joint configuration per frame — that satisfies the supplied end-effector constraints.

It is the high-level motion planner in the v2d (Video-to-Data) robotic grounding pipeline: it converts the hand/object motion recovered from video into a dense, kinematically-consistent whole-body reference, which the SONIC low-level tracking controller then executes.

The model is built on NVIDIA's MotionBricks (GR00T) motion modeling stack and is exported as a self-contained `torch.package` bundle with no GR00T runtime dependency. It is part of the v2d v0.2 release and is under active development.

This model is ready for commercial or non-commercial use.

### Use Case:
This model is intended for robotics researchers and engineers building whole-body humanoid manipulation policies. It generates dense whole-body reference motion from end-effector targets, enabling synthetic-data generation and reference-tracking reinforcement-learning pipelines (e.g., the v2d Video-to-Data grounding pipeline) without requiring full-body motion capture of the target behavior.

## Model Architecture:
**Architecture Type:** Transformer <br>
**Network Architecture:** Other (specify): Autoregressive MotionBricks end-to-end — two transformer modules: a root module (`RootMotionBricksModule`) and a pose module (`PoseMotionBricksModule`) <br>

The planner factors whole-body generation into two transformer modules operating on tokenized motion (4 frames per token; up to 16 tokens, i.e. 64 frames, per autoregressive window):
* **Root module** (~34.5M parameters) — predicts the root XY translation / heading trajectory.
* **Pose module** (~164.5M parameters) — predicts the per-body transforms (270-dim per-frame pose feature) from which the 29-joint configuration is recovered via the bundled humanoid kinematics.

This model has **≈199M parameters** total (34,501,133 root + 164,449,426 pose).

## Input:
**Input Type(s):**
* Other (specify): End-effector and root pose targets

**Input Format(s):**
* Tensor

**Input Parameters:**
* Two-Dimensional (2D)

**Other Properties Related to Input:**
* Root position: 32-bit float tensor with shape `(num_frames, 3)` for (X, Y, Z).
* Root orientation: 32-bit float quaternion tensor with shape `(num_frames, 4)` for (W, X, Y, Z).
* Left and right wrist positions: 32-bit float tensors with shape `(num_frames, 3)`; wrist orientations: 32-bit float quaternion tensors with shape `(num_frames, 4)`.
* Inputs are in the MuJoCo z-up world frame; targets are heading-canonicalized (heading-removed, root-relative) internally before the model.
* Wrist targets supplied at the hand-root body (palm) are converted to the wrist link via a fixed local offset before canonicalization.
* Training-time frame rate is 25 fps; the v2d orchestrator handles up/down resampling outside the model.

## Output:
**Output Type(s):**
* Other (specify): Full-body humanoid robot joint trajectory

**Output Format:**
* Tensor

**Output Parameters:**
* Two-Dimensional (2D)

**Other Properties Related to Output:**
* qpos: `(num_frames, 36)` — root position (3) + root orientation quaternion xyzw (4) + 29 joint positions.
* 29 Unitree G1 body joints, on a fixed humanoid skeleton.
* Generated by chunked autoregressive inference with triangular-weight overlap blending and optional boundary smoothing; an optional lower-body-fixed mode pins the legs to a static seed pose.

## Training and Evaluation Datasets:

### Training Dataset:

### Data Modality:
* Other: Motion-capture-derived skeletal pose trajectories <br>

### Training Data Size:
**Non-Audio, Image, Text Training Data Size:** Approximately 310,000 motion clips. <br>

**Data Collection Method** <br>
Automatic/Sensors <br>

**Labeling Method** <br>
Hybrid: Automatic/Sensors, Manually-Labeled <br>

**Properties:** Trained on the **BONES** motion-capture dataset — an annotated human motion-capture dataset for humanoid robotics research, spanning full-body movements across everyday activities, sports, communication, and dance, provided in a Unitree G1 MuJoCo-compatible format and annotated with up to 6 natural-language descriptions per motion plus temporal phase segmentation with timestamps. A subset is publicly released as **[BONES-SEED](https://huggingface.co/datasets/bones-studio/seed)** (Skeletal Everyday Embodiment Dataset), comprising 142,220 motions (71,132 original + 71,088 mirrored), ~288 hours at 120 fps, captured from 522 performers (253 female, 269 male; ages 17–71; heights 145–199 cm). <br>

### Evaluation Dataset:

**Data Collection Method** <br>
Automatic/Sensors <br>

**Labeling Method** <br>
Hybrid: Automatic/Sensors, Manually-Labeled <br>

**Properties:** Evaluated on a held-out split of **[BONES-SEED](https://huggingface.co/datasets/bones-studio/seed)** (Skeletal Everyday Embodiment Dataset). End-effector tracking accuracy and whole-body joint accuracy are measured against the held-out reference motions. <br>
